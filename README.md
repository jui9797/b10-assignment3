# Burn House

**Burn House** is a modern housing website designed to showcase real estate properties with an elegant and responsive UI. Built using **HTML, CSS, Tailwind CSS, and DaisyUI**, this project provides an intuitive user experience with a sleek and professional design.

## Features
- Fully responsive design
- Modern UI with **DaisyUI components**
- Fast and lightweight **Tailwind CSS** styling
- Easy navigation for users
- Well-structured property listings
- Interactive user interface

## Technologies Used
- **HTML** - For structuring the website
- **CSS** - For additional styling
- **Tailwind CSS** - For utility-based responsive styling
- **DaisyUI** - For pre-designed UI components
